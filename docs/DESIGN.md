# Visual design notes

Direction: handmade paper and a trail of steps. Not a dashboard, not chat.

- **Color**: graph-paper green-grey `#eef3ee`, ink indigo `#1f2a5c` (also the
  default crayon), marigold `#f0b429` (primary action, current step), river teal,
  berry `#a3203f` (destructive only), sheet `#fffef9`. Scenes use soft pastels so
  crayon lines stay the loudest thing on the page. No cream-and-terracotta, no
  gradients.
- **Type**: system fonts only (no remote requests). Headings use a book serif
  (Iowan/Palatino/Georgia) for a storybook voice; interface text uses a humanist
  sans (Trebuchet/Segoe UI). Sentence case, no all caps, no eyebrow labels.
- **Layout**: a note column (step trail, story, one primary action) beside one
  large sheet of paper. On narrow screens the note stacks above the sheet.
  The sheet is capped to the screen height so the page can still be scrolled.
- **Memorable thing**: the child's own lines stay on the scene. Structures stay
  where they were drawn; moving ideas shrink and travel beside the character.
  Everything else is quiet.
- **Motion**: only consequences move (character, friend, weather), driven by the
  confirmed idea and its result level. Under `prefers-reduced-motion` the end
  state is shown at once.
- **Critique pass**: dropped a decorative picture border and a second accent
  color; kept the washi-tape corners because they say "paper" and cost nothing.
